# Example Job Folder

This folder demonstrates how one job should be organized.

- JOB_SPEC.md: job goal and scope
- JOB_BREAKDOWN.md: task structure
- TASKS/: individual task cards
- LOGS/: task logs and changelogs
- HANDOFFS/: team-to-team handoff files
- REPORTS/: completion reports and daily reports
- OUTPUTS/: final artifacts
