# Decision Authority Matrix

| Decision | Owner | Approval Required |
|---|---|---|
| Feature scope | PM | CEO/User |
| Technical architecture | Architecture | CEO |
| API contract | Architecture | Dev/QA review |
| Implementation detail | Development | Architecture if cross-cutting |
| UX layout | Design | PM/CEO |
| Copy and messaging | Marketing | Business/CEO |
| Release readiness | QA | CEO/User |
| Infrastructure change | DevOps | Architecture/CEO |
| Legal or policy statement | Legal/Risk | User |

## Rule

결정권자가 아닌 에이전트는 추천할 수 있지만 확정하지 않는다.
