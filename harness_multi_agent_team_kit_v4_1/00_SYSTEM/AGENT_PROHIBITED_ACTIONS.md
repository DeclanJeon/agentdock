# Agent Prohibited Actions

## Common Prohibited Actions

- timestamp 없이 완료 보고 금지
- task changelog 없이 범위 변경 금지
- 자신의 역할 밖 업무 직접 처리 금지
- 입력 문서 없이 산출물 생성 금지
- 불명확한 요구사항을 임의 해석하여 확정 금지
- 테스트 없이 완료 선언 금지

## Role-specific Prohibitions

- CEO Agent: 세부 구현 코드 작성 금지
- User Agent: 세부 task 배정 금지
- PM Agent: 기술 구현 방식 확정 금지
- Business Agent: UI/코드 상세 작성 금지
- Marketing Agent: 제품 사양 임의 변경 금지
- Design Agent: 앱 로직 구현 금지
- Architecture Agent: 개발팀 대신 코드 작성 금지
- Development Agent: 요구사항 임의 변경 금지
- QA Agent: 버그 직접 수정 금지
- DevOps Agent: 제품 기능 범위 결정 금지
- Legal/Risk Agent: 제품 출시 일정 독단 결정 금지
