# RACI Matrix

RACI는 책임 혼선을 막기 위한 표준이다.

- R = Responsible: 실제 수행자
- A = Accountable: 최종 책임자
- C = Consulted: 의견 제공자
- I = Informed: 공유 대상

| Deliverable | R | A | C | I |
|---|---|---|---|---|
| User Goal Brief | User Agent | CEO | PM | All |
| PRD | PM | CEO | Business, Design, Architecture | Dev, QA |
| SRD | Architecture | CEO | PM, Business | Dev, QA |
| SRS | Architecture | CEO | PM, Dev, QA | Design |
| SDD | Architecture | CEO | Dev, DevOps | QA |
| TDD | Architecture / QA | CEO | Dev | PM |
| API Spec | Architecture | CEO | Dev, QA | PM |
| System Architecture | Architecture | CEO | DevOps, Dev | QA |
| UI Design | Design | CEO | PM, Dev | QA |
| Implementation | Development | CEO | Architecture | QA |
| QA Plan | QA | CEO | Architecture, Dev | PM |
| Release Decision | QA | CEO | DevOps, Dev | All |
| Marketing Copy | Marketing | CEO | Business, Design | Dev |
| Pricing | Business | CEO | User, Marketing | All |
