# Definition of Done

완료는 “했다”가 아니라 “검증 가능한 기준을 통과했다”는 뜻이다.

## Common DoD for All Teams

- WORK_CHECKLIST 작성 완료
- TASK_LOG에 주요 작업 기록
- TASK_CHANGELOG에 추가/삭제/수정 기록
- 산출물 파일 작성
- self-review 완료
- handoff 또는 completion report 작성
- timestamp 기록

## Architecture DoD

- PRD 검토 완료
- SRD 작성 완료
- SRS 작성 완료
- SDD 작성 완료
- TDD 작성 완료
- API_SPEC 작성 완료
- SYSTEM_ARCHITECTURE 작성 완료
- FLOW_DIAGRAM 작성 완료
- SEQUENCE_DIAGRAM 작성 완료
- 개발팀 handoff 작성 완료
- 모호한 요구사항 목록 작성 완료

## Development DoD

- 구현 완료
- 타입 체크 통과
- lint 통과
- unit/integration test 통과
- 변경 파일 목록 기록
- known limitation 기록
- QA handoff 작성 완료

## Design DoD

- UX flow 정의
- wireframe 또는 layout 작성
- design system token/spacing/type 정의
- edge state 정의
- dev handoff 작성

## QA DoD

- QA plan 작성
- normal case 검증
- edge case 검증
- regression 검증
- bug report 작성
- release decision 작성

## Business / Marketing DoD

- 목표 고객 정의
- 메시지와 포지셔닝 정의
- 채널별 실행안 작성
- 성공 지표 작성
- 리스크 기록
