# Adaptive Orchestration Checklist (CLI-only)

- [x] `adock job "..."` is the primary user entry point.
- [x] Simple jobs do not require a team.
- [x] CEO can reuse running roles before recruiting new roles.
- [x] Team size is capped by job complexity/risk.
- [x] Role reports are required for selected roles.
- [x] QA/review gates block critical finalization when missing.
- [x] TFT records capture temporary blocker teams only when needed.
- [x] Meeting records capture decisions without unbounded chat loops.
- [x] Runtime model settings persist and can be applied to running Hermes panes.
- [x] Optional worktree mode is available for role isolation.
- [x] Desktop app, UI bridge, native visual harnesses, and generated visual assets are removed.
